## About

This presentation is designed for the workshop **Crafting Your Academic Story**.

It helps participants think about academic presentations through three connected ideas:

- **Story** — what you say and how the argument is structured
- **Screen** — how the story is represented visually
- **Stage** — how attention is guided through delivery

The central story framework is:

**WHY → HOW → WHAT → SO WHAT → NOW WHAT**

## Presentation Controls

The presentation works with a keyboard and most wireless PowerPoint presenters.

| Action | Key |
|---|---|
| Next slide | `Right Arrow`, `Page Down`, `Space`, or `N` |
| Previous slide | `Left Arrow`, `Page Up`, or `P` |
| First slide | `Home` |
| Last slide | `End` |
| Replay animation | `R` |
| Fullscreen | `F` |
| Open menu | `M` |
| Coach notes | `C` |
| Exit an input field / close menu | `Esc` |

When typing in an activity field, slide navigation is temporarily disabled so the wireless presenter does not accidentally change slides.

## Universal Font Controls

Use the menu on the right side of the presentation to adjust:

- All text size
- Title size
- Bullet size
- Diagram text size
- Diagram size
- Spacing

These settings are **universal** and stay consistent across all slides.

The selected settings are also saved in the browser using local storage, so they remain after refreshing the page on the same device.

## GitHub Pages

This repository is designed to run directly with **GitHub Pages**.

Recommended repository structure:

```text
crafting-academic-story/
├── index.html
├── .nojekyll
├── README.md
└── js/
    └── gsap.min.js   # optional for full offline GSAP animation
```

To publish:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select:
   - Branch: `main`
   - Folder: `/(root)`
5. Click **Save**.
6. Wait for GitHub Pages to finish deploying.

The published presentation is available at:

[https://yashmgupta.github.io/crafting-academic-story/](https://yashmgupta.github.io/crafting-academic-story/)

## Offline Use

The presentation can also be used without GitHub Pages.

1. Keep the complete presentation folder on your laptop or USB drive.
2. Open `index.html` in Chrome or Edge.
3. Press `F` for fullscreen.

The presentation includes fallback animations for offline use.

For full GSAP animation while completely offline, place:

```text
js/gsap.min.js
```

inside the `js` folder.

## Recommended Workshop Setup

For reliable delivery:

- Use Chrome or Microsoft Edge.
- Connect the laptop to power.
- Plug in the wireless presenter before opening the presentation.
- Open the GitHub Pages link.
- Click once inside the presentation.
- Press `F` for fullscreen.
- Test forward and back buttons before participants arrive.
- Keep an offline copy of the full folder on the laptop.
- Keep a second backup on a USB drive.
